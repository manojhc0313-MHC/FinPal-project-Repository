FinPal - Your Intelligent Financial Assistant 💰
FinPal is an interactive web application designed to simplify personal finance management. It not only helps you track your income and expenses but also leverages machine learning to provide intelligent insights, helping you budget smarter and invest wiser.

The Problem
In today's fast-paced world, managing finances can be overwhelming. Many people struggle to understand their spending habits and make informed decisions about their savings. FinPal solves this by providing a simple, smart, and data-driven solution to take control of your financial health.

Key Features
Interactive Dashboard: A clean and user-friendly interface built with Streamlit to visualize your complete financial picture at a glance.

Real-Time Tracking: Easily add and categorize your income and expenses, with the dashboard updating instantly.

Expense Prediction: A machine learning model powered by Scikit-learn forecasts your total expenses for the upcoming month, helping you plan your budget.

Personalized Recommendations: An intelligent engine analyzes your savings and provides actionable tips on investment strategies, from building an emergency fund to investing in mutual funds.

Data Visualization: An interactive pie chart built with Plotly gives you a clear and engaging breakdown of your spending categories.

Tech Stack
Language: Python

Web Framework: Streamlit

Data Manipulation: Pandas

Machine Learning: Scikit-learn

Plotting: Plotly

How to Run the Project
Clone the repository to your local machine.

Create the Conda environment: conda create --name finpal_env python=3.10

Activate the environment: conda activate finpal_env

Install the required libraries: pip install -r requirements.txt

Run the application: streamlit run app.py
